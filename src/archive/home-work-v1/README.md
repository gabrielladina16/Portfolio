# Archived Home + Work v1

This folder preserves the Home vinyl gallery and three-column Work page as they
looked on 2026-09-06. They are intentionally disconnected from the live router.

To restore them later, import `ArchivedHomeGallery` and `ArchivedWork` into
`src/main.js`, then add their routes back to `src/components/Header.js`.

The archived components keep using the existing gallery, project-card, and Work
selectors in `src/styles/components.css`, `src/styles/layout.css`, and
`src/styles/responsive.css`.
